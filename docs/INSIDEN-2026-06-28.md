# Insiden & Pemulihan Source — 28 Juni 2026

**Untuk: Pa Chacha (dev).** Ringkasan kejadian + kondisi sekarang + utang teknis.

## Apa yang terjadi
Saat menyunting `brain/Program.cs` (membersihkan karakter non-ASCII), sebuah perintah tulis-ulang file **gagal di tengah dan meng-kosongkan `brain/Program.cs` jadi 0 byte**. Source brain hilang.

Tidak ada salinan bersih saat itu:
- `.git/` kosong (belum jadi repo aktif), tanpa remote.
- `backups/*.zip` waktu itu **tidak** menyimpan file `.cs` (hanya auth/config/data).
- Tidak ada VS Code local history / OneDrive / shadow copy.
- `Program.cs.bak-mojibake` terlalu tua (sebelum leaderboard/analisa).

**Bot LIVE tidak pernah mati** — proses brain tetap jalan dari assembly di memori selama pemulihan.

## Cara pemulihan (berhasil)
Decompile DLL hasil build hari itu (`brain/bin/Debug/net10.0/WaBot.dll`, = kode terbaru) memakai library `ICSharpCode.Decompiler` dengan `DecompilerSettings.LocalFunctions = false` (ilspycmd crash di transform local-function), lalu identifier compiler-generated disanitasi via regex (`<>c__DisplayClass`→`DC_`, `<<Main>$>g__X|N`→`lf_X_N`, dst). Hasil compile bersih (Debug & Release) dan di-deploy.

Artefak pemulihan ada di `RECOVERY/` (di-gitignore): `WaBot.full.decompiled.txt`, `decomp-per-class/`.

## Kondisi `brain/Program.cs` SEKARANG (penting)
Fungsional 100% setara, TAPI bentuk **decompile**:
- **Tanpa komentar** (komentar asli hilang).
- **Nama ter-mangle**: `DC_0_0` (display class), `lam_21` (lambda), `lf_PostJson_0_40` (local function), `CS_cl8_278`/`CS_cl8_472` (closure instance).
- **Logika terduplikasi**: beberapa local function yang dulu satu kini ter-inline jadi 2 salinan. Contoh: handler jawaban-puzzle + handler `!puzzle` + handler `!solusi` masing-masing muncul DUA kali (satu di `lam_21` `/incoming` pakai `CS_cl8_278.msg`, satu lagi pakai `msg`+`CS_cl8_472`). **Tiap edit puzzle harus disisipkan ke KEDUA salinan.**
- **Bukan ASCII-hardened** lagi (ada unicode literal; rawan mojibake cp1252). File `.cs` LAIN (BoardRenderer/BoardVision/Ccl/ChessEngine) tidak tersentuh & masih asli.
